# Calisthenics Progression Ladders (shared reference)

Skill-progression ladders. **Current levels are tracked per person** in `people/<name>/calisthenics_status.md` — this file only defines the ladders.

Rules: skill work stays **frequent, low-fatigue, and technical** — never trained to failure. Advance a level only when the **target** is met with clean form. Prep wrists before any hand-balancing or straight-arm work.

How targets are set (revised 2026-07-13, research-aligned):
- **Dynamic moves:** sets × reps (e.g. 3×8) — total volume at sub-failure effort, never one max set.
- **Isometrics:** one solid hold at the stated seconds (typical session: 3–5 shorter holds accumulating 2–3× that).
- Every target is a single crisp threshold so a level-up is unambiguous.

## PULL

### Muscle Up
Prereqs: strict pull-ups + dips. Keep explosive work low-volume (CNS, not metcon).
| Lvl | Stage | Target |
|---|---|---|
| 1 | Pull Up | 10 strict |
| 2 | High Pull Up | pull to lower chest/sternum, 6 reps |
| 3 | Jumping Muscle Up | clean transition, minimal leg assist, 6 reps |
| 4 | Kipping Muscle Up | 5 with minimal kip |
| 5 | Muscle Up | 5 strict clean reps |
